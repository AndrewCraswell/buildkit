# Buildkit agent guidance

Read [.github/copilot-instructions.md](.github/copilot-instructions.md) before changes. Use pnpm 12 on Node 24+, oxlint,
oxfmt, native TypeScript, Vitest, and Turborepo. Run `pnpm verify` before finishing; never bypass Git hooks.

Put worktrees under `D:\system\worktrees\buildkit\<name>`. Remove worktrees and merged branches when done.
